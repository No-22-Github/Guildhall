# 工作台与像素公会前端

大厅使用生成的房间底图与透明角色图集，HTML 按钮提供角色入口、委托纸张和状态数量。所有操作继续调用现有 API；场景组件不执行请求。

## 工作台

- `workbench` 为新增内置布局。首次访问及未知皮肤 ID 回落工作台；已有 `tavern` / `moonlight` 浏览器选择保留。
- 左侧项目筛选作用于任务列表、数量和最近任务；新任务表单明确显示所属项目，进入现有任务始终使用该任务自己的项目。窄屏保留图标导航，并在列表页显示项目筛选。
- 任务列表按创建时间倒序，全部任务包括归档记录；执行队列、验收与审阅、归档分别沿用现有状态筛选。
- 工作台将同一份 Chat / Review / Settings 内容放在常驻工作区，酒馆仍使用模态面板。切换外观复用已挂载表单，避免丢失未保存模型配置；离开有草稿的页面时显示继续编辑 / 放弃修改提示。
- 对话隐藏像素场景，保留工具记录、运行详情、Markdown、可调整宽度的需求单及专注阅读。窄屏展开需求单时占据主区域，可返回对话。
- 审阅采用 shadcn/ui Tabs，将验收证据、完整 diff、需求单分开阅读。验收失败、测试变更警告、越界文件与合并确认继续保留。
- `guildhall.colorMode` 保存 `light` / `dark` / `system`，默认跟随系统；监听系统变化和跨标签页存储事件。外观设置仅保存在浏览器，不改后端模型配置。
- `frontend/src/workbench.css` 定义工作台作用域下的语义颜色；浅色为灰绿纸面、深色为炭灰绿色。代码、工具输出、错误、警告和验收结果使用同一套颜色变量。
- shadcn/ui 组件源码位于 `frontend/src/components/ui/`，配置在 `frontend/components.json`。使用 Button、Input、Textarea、Badge 和 Radix Tabs，后续可按 [官方 Vite 安装说明](https://ui.shadcn.com/docs/installation/vite) 增加组件。

## 操作覆盖

- 前台面板选择或登记项目，选择只用于这次新委托。大厅跨项目展示；委托板、冒险者、鉴定台和档案柜各自在面板内筛选项目。委托卡片与对话/审阅面板显示所属项目。
- 场景中的公会手册提供模型设置与换肤入口。
- 前台新建或继续草稿对话，生成、编辑、张贴委托，放弃草稿。
- 委托板显示当前项目的活跃委托，支持标题、编号与状态搜索。
- 冒险者面板包含待派单、执行中和失败委托；详情保留派单、推进验收、重试与恢复入口。
- 鉴定台包含鉴定中、待过目与有争议委托；详情保留 diff、逐项证据、重验、接受并合并及放弃。
- 档案柜访问已接受与已放弃单据，直接打开审阅详情。
- 模态面板支持 Escape、焦点约束。窄屏提供较大设施快捷按钮与纵向审阅布局。减少动画遵循系统偏好或设置页选项。

## 皮肤约定

`frontend/src/skins/index.ts` 定义 Skin 与皮肤注册表。提供工作台、琥珀酒馆，以及复用素材的月光配色变体。`layout: workbench` 使用工作台容器，不加载场景素材。

每份配置包含底图、透明角色图集、色调、UI 强调色、设施语义 ID、百分比坐标、角色帧与柜台遮挡裁切。新增皮肤可替换资源和布局，不需要改业务代码。场景视图位于 `frontend/src/components/TavernScene.tsx`。

当前美术规格：房间 16:9；角色图集由三个等宽单元构成，依次为前台、冒险者、鉴定师。图集需有真实透明通道。CSS background-position 选择单元；clipBottom 控制柜台后的下身遮挡。设施暂时包含在房间底图中，独立角色和真实委托纸张为覆盖层；后续若要移动家具或增加角色动作，可扩展 Skin 为设施图层与动画帧配置。

皮肤 ID、减少动画、最近选择项目仅存浏览器 localStorage。密钥不进 localStorage。未知皮肤 ID 回落默认皮肤。两套酒馆色调复用同一房间素材。

## 模型设置

GET/PUT `/api/settings` 只暴露三角色的 model、base_url、has_token 及配置 revision。PUT 的 auth_token 为空或 null 时保留，clear_token=true 显式清除。默认项使用当前后端进程环境或 Claude 默认登录凭据，不在角色之间继承。

使用 tomlkit 保留其他 TOML 段落与注释；保存通过 revision 拒绝覆盖过期配置，并以权限 0600 的临时文件原子替换 config.toml。验证错误不回显输入，API URL 禁止内嵌凭据、查询和片段。设置端点拒绝非本机 Origin。

配置保存后需要重启后端，运行中的 Agent 与委托保持原配置；界面根据磁盘配置与启动配置的差异显示等待重启。密钥从不回传，页面重开后仅显示是否已设置。未保存模型配置关闭时会提示；保存期间禁止关闭。

## 验证与开发

- `cd frontend && pnpm build` 与 `pnpm lint`
- `cd backend && uv run pytest -q`
- 浏览器使用临时 Git 仓库、隔离 Guildhall 目录、fake ACP 验证新建、生成、张贴、派单、异常鉴定展示、设置保存及窄屏重排。真实模型判断能力不在这次验证范围。
- Vite 可用 `GUILDHALL_API_URL` 指定测试后端，缺省仍为 127.0.0.1:8420。`VITE_GUILDHALL_DEMO=1` 显示隔离演示标识。

素材与生成提示词见 `frontend/public/skins/tavern/README.md`。
